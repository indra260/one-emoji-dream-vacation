## The entry

> 🏝

One emoji, nothing else: a desert island — a palm tree on a speck of sand in the middle of the sea.

## Why this emoji

A desert island is the dream vacation distilled to a single picture. At a glance it is a whole postcard: sun, sand, palm, open water, and nobody else around — the fantasy of escaping to somewhere unreachable, not just any holiday but *the* one you daydream about when work gets loud. It is specific (one tiny island, one palm, one patch of sand) rather than a generic sun or plane, yet it reads instantly in every culture and at any size, because the palm-on-an-island image is the universal shorthand for paradise. And there is a quiet joke in it: the dream is not a resort with a thousand rooms, it is a place so small it barely exists — the ultimate "do not disturb". Technically it is also a safe pick: U+1F3DD is a single Unicode code point with no variation selector, so it counts as exactly one character under any counting method.

## Run

```sh
node main.ts
```

This writes the emoji (exactly one code point, U+1F3DD, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
